# Dibba Bolega

A mobile-first interactive prototype for village waste collection, routing, stock, ratings, complaints, and recycling enquiries. It uses simulated data stored only in the current browser session; there is no backend or payment processing.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL shown in the terminal. Choose a role and demo user to explore the connected Villager, Driver, Gram Panchayat, and Buyer workflows.
